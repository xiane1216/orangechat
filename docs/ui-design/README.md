# 聊天界面改版方案（已定稿 v7）

> 本文档是 UI 改版的交接说明。新会话/新开发者请先读完本文再动手。
> 打开 `imessage-proposal.html`（浏览器直接打开）可交互体验**已定稿**的目标 UI（v7）。

## 用户确认的设计决策（v7 定稿）

用户偏好：简洁、精致、字小，"就像 iOS 的 iMessage 短信界面"。

### 布局总览

1. **无时间戳**：聊天区不显示任何时间戳（手机系统状态栏的时间保留）
2. **无头像**：完全 iMessage 式布局，消息区不显示双方头像
3. **顶栏**：左上 ☰ 三条杠（打开侧边栏）+ 居中小圆头像（28px）+ 助手名（11px 灰字）
4. **界面零按钮**：复制/翻译/重新生成/朗读/编辑/删除等操作**不常驻显示**，
   全部收进**长按消息弹出的深色磨砂上下文菜单**（iOS 风格：圆角、backdrop-blur、小箭头指向消息）
   - AI 消息菜单：拷贝 / 翻译 / 朗读 / 重新生成 / 删除
   - 用户消息菜单：拷贝 / 编辑重发 / 删除

### 气泡（重要细节）

5. **样式**：
   - 用户消息：右侧，品牌紫（浅色 `#4B3FE3` / 深色 `#6054F1`），白字
   - AI 消息：左侧，浅灰（浅色 `#E9E9EB` / 深色 `#26262A`）
   - 圆角 17px；正文字号 14px（用户明确要求字小）
6. **拆分气泡分组**（用户一次发送 / AI 一轮回复都会拆成多条气泡）：
   - 组内间距 3px，换人间距 14px
   - **第一条气泡带 5px 小圆角**（靠屏幕边那侧的底角），后续都是完整 17px 圆角
   - 注意：橘瓣现有拆分气泡功能存在**组内间距不均**的问题，实施时需排查修好
7. **AI 正在回复**：一个气泡内三个 5px 小圆点跳动（typing indicator），回复完成后气泡替换为正文

### 思考链与工具调用

8. **一轮回复一个 ✦**（不是一条气泡一个）：挂在整轮拆分气泡组的末尾，很淡的小图标，点击展开/收起
   - 展开后分两小节：「思考」（斜体小灰字）、「工具」（如 `🔧 web_search「xxx」→ 结果摘要`）
   - 流式生成中若正在调用工具，可临时显示"正在调用 xxx…"，完成后收进 ✦

### ＋ 功能面板（微信式）

9. **点 ＋ 后面板从底部弹出，输入框被顶到面板上方**（微信交互）；再点收起
10. **黑色线条图标**（stroke 1.6、随主题变白线），不要 emoji；10 个入口：
    拍照 / 相册 / 文件 / 语音通话 / 模型 / 联网搜索 / 深度思考 / MCP / 插件管理 / 压缩历史
    （原 UI 的模型/搜索/思考开关、顶栏语音通话都收进这里）
11. **输入栏**：＋ 圆形按钮 + 胶囊输入框 + 圆形 ↑ 发送键（iMessage 同款）

### 背景图与透明气泡（新功能）

12. **显示设置加开关：透明气泡**（iMessage 透明气泡效果），开启后：
    - AI 气泡：`rgba(255,255,255,0.1)` 玻璃底 + `blur(7px) saturate(170%)` + 白字 + 0.5px 半透明描边
      ——**不要白色蒙层**，要直接透出背景图的色系（用户强调过"发白"不好看）
    - 用户气泡：`rgba(96,84,241,0.38)` + blur
    - 顶栏：背景图延伸到顶栏底下（透明化），顶部叠黑色 36%→0 的 scrim 渐变保文字可读
    - 输入区：输入框/＋/↑ 变毛玻璃胶囊浮在背景上，底部叠 scrim 渐变
    - ＋ 面板：深色磨砂 `rgba(16,14,26,0.72)` + blur(24px)
13. 演示稿顶部有「壁纸」「透明气泡」两个开关可体验效果

## 交互细节（见演示稿 JS 实现）

- 长按 450ms 触发菜单（移动端带震动反馈），桌面端右键同样触发
- 菜单操作以 toast 反馈（如"已拷贝"）
- 深浅色主题跟随系统，演示稿带手动切换按钮
