# 聊天界面改版方案（进行中）

> 本文档是 UI 改版的交接说明。新会话/新开发者请先读完本文再动手。
> 打开 `imessage-proposal.html`（浏览器直接打开）可交互体验已确认的目标 UI。

## 当前状态

- 设计方向已与用户确认（v2 iMessage 风格），**代码尚未开始修改**
- v1 微信风格方案（头像+气泡+点击浮现工具栏）已被用户否决，仅存档于 `v1-wechat-proposal.html`，勿采用

## 用户确认的设计决策（v2 · iMessage 风格）

用户原话偏好：简洁、精致、字小，"就像 iOS 的 iMessage 短信界面"。

1. **无时间戳**：聊天区不显示任何时间戳（手机系统状态栏的时间保留）
2. **无头像**：完全 iMessage 式布局，消息区不显示双方头像
3. **界面零按钮**：复制/翻译/重新生成/朗读/编辑/删除等操作**不常驻显示**，
   全部收进**长按消息弹出的深色磨砂上下文菜单**（iOS 风格：圆角、backdrop-blur、小箭头指向消息）
   - AI 消息菜单：拷贝 / 翻译 / 朗读 / 重新生成 / 删除
   - 用户消息菜单：拷贝 / 编辑重发 / 删除
4. **思考链折叠为小图标**：AI 消息气泡下方一个很淡的 ✦ 图标，点击展开/收起；
   展开后以一行 11px 灰色斜体小字显示在气泡下方
5. **输入框 iMessage 同款**：底部一行 = 左侧 ＋ 圆形附件按钮 + 中间胶囊输入框 + 右侧圆形 ↑ 发送按钮
6. **气泡样式**：
   - 用户消息：右侧，品牌紫（浅色 `#4B3FE3` / 深色 `#6054F1`），白字
   - AI 消息：左侧，浅灰（浅色 `#E9E9EB` / 深色 `#26262A`）
   - 圆角 17px；连续同一方消息分组：组内间距 3px，第一条带 5px 小尾角，换人间距 14px
   - 正文字号 14px（用户明确要求字小）
7. **顶部栏**：极简居中——小圆头像（28px）+ 名字（11px 灰字）

## 交互细节（见演示稿 JS 实现）

- 长按 450ms 触发菜单（移动端带震动反馈），桌面端右键同样触发
- 菜单操作以 toast 反馈（如"已拷贝"）
- 深浅色主题跟随系统，演示稿带手动切换按钮
